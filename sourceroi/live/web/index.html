Quick start
Run these commands from your VS Code terminal

            
01
Install
python3 -m pip install -e '.[dev]'

            
02
Import your documents
python3 -m sourceroi init --documents /path/to/mydata --output myworkspace

            
03
Add expected answers
Edit myworkspace/benchmark.jsonl. Use independently checked facts, not answers invented by the model being tested.

            
04
Connect a real model
export OPENAI_API_KEY="your-key"
Or edit project.json for a local OpenAI-compatible model or an existing agent endpoint.

            
05
Launch your workspace
python3 -m sourceroi --project myworkspace serve

          

        

        
Data & privacy boundaries
Local history
Run traces and benchmark answers are stored locally in SQLite, without encryption at rest.
Model calls
Selected source excerpts leave your machine when you use a hosted model. Get permission first.
No hosted authentication
UI is localhost-only. Do not deploy it publicly or expose through a tunnel.
Cost truthfulness
Dollar costs require configured provider rates or agent-reported billing. Unknown means unknown.
